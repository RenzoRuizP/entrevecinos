# Ajuste modal Ayuda EV y cierre de Revisar publicación

## Cambios

- Ayuda EV queda sin botón X.
- Ayuda EV no se cierra al pulsar fuera ni con Escape; solo mediante **Aceptar**.
- Se retiraron los tres mensajes de reglas básicas solicitados.
- Se mantiene la descripción general y el canal exclusivo de WhatsApp.
- El modal Revisar publicación usa la misma X estática de los modales EV estándar, sin rotación ni animación.

## Base de datos

No requiere cambios SQL.
